# Proyecto de Machine Learning con datos del DANE

## Descripción

En este proyecto se aplicaron técnicas de análisis de datos y machine learning utilizando Python, pandas y scikit-learn, con el propósito de analizar variables demográficas de una base de datos del DANE y predecir el sexo de una persona.

La pregunta de investigación planteada fue:

**¿Es posible predecir el sexo de una persona a partir de variables demográficas y familiares como edad, parentesco, padre y madre?**

## Base de datos

Se utilizó la base de datos **Personas** obtenida del catálogo de microdatos del DANE.

## Variables utilizadas

### Variable objetivo

* SEXO

### Variables explicativas

* EDAD
* PARENTESCO
* PADRE
* MADRE

## Herramientas utilizadas

* Python
* Pandas
* Scikit-learn
* Random Forest Classifier
* Google Colab

## Resultados

El modelo obtuvo una exactitud aproximada de **59.7%**, logrando identificar patrones en los datos y realizar predicciones correctas en más de la mitad de los casos.

También se obtuvieron:

* **20,227 aciertos**
* **13,643 errores**
